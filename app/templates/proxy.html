پروکسی سرورهای RDP

روی سرورهای RDP / ترمینال همهٔ کاربران با یک IP به اینترنت می‌روند و روتر نمی‌تواند آن‌ها را از هم جدا کند. مرورگرهای آن سرورها از این پروکسی استفاده می‌کنند؛ هر کاربر یک بار نام کاربری و رمز ویندوز (دامنه) خود را وارد می‌کند و از آن به بعد حجم، ساعات مجاز، قفل و سایت‌های مسدود دقیقاً مثل هات‌اسپات برای همان کاربر حساب و اعمال می‌شود. اتصال‌ها با سرویس «پروکسی» در گزارش‌ها و کاربران آنلاین دیده می‌شوند.

تنظیم ویندوز (GPO روی سرورهای RDP)

در Group Policy یک GPO به OU سرورهای RDP لینک کنید (با Loopback Processing = Merge تا تنظیمات کاربری روی همان سرور اعمال شود): User Configuration ‹ Preferences ‹ Control Panel Settings ‹ Internet Settings ‹ New ‹ Internet Explorer 10، تب Connections ‹ LAN settings:

Proxy server: {{ host }} Port: {{ st.port }} Bypass proxy server for local addresses: ✓ Exceptions: 192.168.*;10.*;172.16.*;*.corp.local;localhost

کروم و Edge همین تنظیم ویندوز را می‌خوانند. فایرفاکس: Settings ‹ Network Settings ‹ Use system proxy settings. بار اول مرورگر پنجرهٔ ورود نشان می‌دهد؛ نام کاربری بدون دامنه هم قبول است (m.karimi یا CORP\m.karimi). مرورگر رمز را تا بسته شدن نگه می‌دارد؛ با «ذخیرهٔ رمز» دیگر پرسیده نمی‌شود.

تنظیم میکروتیک

تا کاربران سرور RDP نتوانند بدون پروکسی بیرون بروند: IP سرور RDP و سرور برنامه را در «استثناها» (صفحهٔ کنترل دسترسی) بگذارید تا هات‌اسپات لاگین نخواهد، بعد فقط ترافیک مستقیم سرور RDP به اینترنت را ببندید:

/ip firewall address-list add list=internal address=10.0.0.0/8 /ip firewall address-list add list=internal address=172.16.0.0/12 /ip firewall address-list add list=internal address=192.168.0.0/16 /ip firewall filter add chain=forward src-address=RDP_SERVER_IP dst-address-list=!internal action=drop comment="RDP only via proxy" place-before=0

سرور برنامه خودش باید به اینترنت دسترسی داشته باشد (پروکسی از طرف کاربران وصل می‌شود). اگر سرور برنامه پشت هات‌اسپات است، آن را هم در استثناها بگذارید. پورت {{ st.port }} را در فایروال ویندوز سرور برنامه برای IP سرورهای RDP باز کنید:

New-NetFirewallRule -DisplayName "Accounting proxy" -Direction Inbound -Protocol TCP -LocalPort {{ st.port }} -RemoteAddress RDP_SERVER_IP -Action Allow
