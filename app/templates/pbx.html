آماده‌سازی روی ایزابل (یک بار، با SSH به ایزابل)

۱) کاربر فقط‌خواندنی بسازید (رمز root دیتابیس در /etc/issabel.conf با نام mysqlrootpwd است؛ APP_IP = IP همین سرور برنامه):

mysql -u root -p -e "CREATE USER 'acct_reader'@'APP_IP' IDENTIFIED BY 'StrongPass'; GRANT SELECT ON asteriskcdrdb.* TO 'acct_reader'@'APP_IP'; FLUSH PRIVILEGES;"

۲) اگر MySQL فقط روی localhost گوش می‌دهد، در /etc/my.cnf خط bind-address=127.0.0.1 را حذف یا به IP ایزابل تغییر دهید و systemctl restart mariadb (در نسخه‌های قدیمی service mysqld restart). ۳) پورت 3306 را فقط برای IP سرور برنامه باز کنید (در ایزابل: Security ‹ Firewall، یا iptables -I INPUT -p tcp -s APP_IP --dport 3306 -j ACCEPT). این کاربر فقط اجازه خواندن دارد و برنامه هیچ تغییری در ایزابل نمی‌دهد.

۴) برای تماس‌های زنده (اختیاری) این چند خط را به انتهای /etc/asterisk/manager_custom.conf اضافه کنید، سپس asterisk -rx "manager reload" را اجرا کنید و پورت 5038 را فقط برای IP سرور برنامه باز کنید. این کاربر فقط اجازهٔ خواندن وضعیت تماس‌ها را دارد:

[acct_live]
secret = StrongPass2
deny = 0.0.0.0/0.0.0.0
permit = APP_IP/255.255.255.255
read = call,reporting
write = reporting
